CARRINHO INTELIGENTE

Projeto com Arduino

Nosso Carrinho Inteligente utiliza um sensor ultrassônico para identificar obstáculos e um Arduino para controlar os alertas luminosos e sonoros.

Projeto desenvolvido por estudantes da Etec Sales Gomes, em Tatuí - SP.

Conhecer os componentes

Componentes Utilizados

Conheça os principais componentes utilizados na montagem do nosso projeto.

Arduino Uno

É responsável por receber os dados do sensor e controlar os alertas.

Sensor HC-SR04

Mede a distância dos obstáculos utilizando ondas ultrassônicas.

Módulo Relé 5V

Funciona como um interruptor controlado pelo Arduino.

Buzzer

Emite sinais sonoros para avisar sobre obstáculos próximos.

Fita LED

Realiza a sinalização luminosa do carrinho.

Protoboard

Permite montar e testar as conexões sem solda.

Fonte de Alimentação

Fornece energia elétrica para os componentes do projeto.

Fios Jumper

Fazem as conexões entre o Arduino, o sensor e os demais componentes.

Projeto Elaborado

Confira o resultado da montagem do nosso Carrinho Inteligente.

O projeto reúne programação e eletrônica para detectar obstáculos e emitir alertas. Durante a montagem, utilizamos componentes eletrônicos e realizamos testes para verificar o funcionamento do sistema.
